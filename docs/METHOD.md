# 方法说明

[项目首页](../README.md) · [实验结果](EXPERIMENTS.md) · [代码导航](CODE_MAP.md)

## 固定语义参照

LBIF 使用增强 CLIP ViT-L/14 检测器，沿用第8、16、24层跨层读出。新增局部适配阶段冻结完整增强语义路径，使用 $b(x)=S(x)/2$ 作为固定 logit 参照。语义与局部输入按帧身份配对，分辨率分别为224×224与256×256。

## 有符号误差与局部表征

局部输入为 $E=x-G(x)$，高斯核为5×5，标准差为1，采用反射填充。卷积编码器依次输出16、32、64通道，后两阶段下采样，得到64×64×64特征。学习特征相对5×5邻域均值的绝对偏离为 $C=|F-\mathrm{AvgPool}(F)|$。

## 边界读出与融合

带跳跃连接的解码器预测边界logit。边界概率停止梯度后按面积下采样为位置权重 $W$，聚合得到64维局部向量：

$$q_c=\frac{\sum_p W_p C_{c,p}}{\max(\sum_p W_p,\,0.25N)},\qquad N=4096.$$

无偏置线性头零初始化，局部修正为 $\delta=0.5\tanh(w^\top q)$，融合输出为 $z=\mathrm{sg}(b)+\delta$。初始 $\delta=0$；有界约束限定输出扰动幅度，AUC收益由匹配实验评价。

## 训练目标

| 目标 | 学习依据 | 权重 |
| :--- | :--- | ---: |
| 整图分类 | 融合logit与图像真假标签 | 1 |
| 软边界监督 | 掩膜平滑后构造 $T=4a(1-a)$ | 0.2 |
| 块级分类 | 16×16上下文网格，掩膜覆盖率严格大于0.1标为伪造 | 0.2 |
| 图内区域对比 | 同一有效伪造图中的真假块，温度0.5 | 0.1 |
| 修正平方正则 | $\mathrm{mean}(\delta^2)$ | 0.01 |

图内对比要求真假两类各至少两个块，并排除自配对。无效伪造掩膜跳过局部辅助目标，图像仍参与整图分类；不将缺失掩膜补成全零监督。

## 推理

推理仅输入图像，保留预测边界解码器，移除辅助块分类头，不使用真实掩膜。每个视频固定32帧，先计算sigmoid概率，再按原顺序以FP64求平均。

新增局部训练参数为118,722个，参与图像推理的局部参数为118,657个；两者均不包含冻结语义基座。
