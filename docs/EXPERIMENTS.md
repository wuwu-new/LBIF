## 完整匹配控制

| 配置 | 六域视频Macro（%） | Δ相对LBIF（pp） |
| :--- | ---: | ---: |
| 增强语义基线 | 88.870 ± 0.411 | -0.239 |
| RGB 输入 | 88.854 ± 0.429 | -0.255 |
| 无块级分类 | 88.936 ± 0.545 | -0.173 |
| 无区域对比 | 89.110 ± 0.428 | +0.002 |
| 无联合块级目标 | 88.937 ± 0.496 | -0.172 |
| 均匀池化 | 89.212 ± 0.366 | +0.103 |
| LBIF | 89.109 ± 0.375 | 0.000 |

对应论文表4与附录表A1。五项控制分别替换输入、关闭块级分类、关闭图内对比、关闭两项块级目标及改用均匀池化。所有双流控制保留边界监督，沿用同一训练预算和评价清单。

完整模型相对RGB输入控制及无联合块级目标控制分别高0.255和0.172个百分点。无区域对比的均值接近完整模型，均匀池化的均值更高；这些结果不支持将每个辅助项或边界加权都描述为已验证的独立增益。
