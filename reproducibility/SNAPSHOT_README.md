# 代码第一版

本备份对应论文《局部监督驱动的有界增量融合人脸伪造检测》及第五章优化版，创建于2026年11月9日。

remote_runs 保存完整双流的训练与推理实现、五项匹配消融、语义三种子与CrossLayerNoImage基座代码，以及各自冻结配置和注册信息。
training_data 保存实际TRAIN和VAL图像、语义对齐图像、可用掩膜及候选掩膜、原始划分清单和冻结语义分数。
原始掩膜有效性标记保持不变，候选掩膜不等同于有效监督；原始清单完整保留。
training_data/files 下按原绝对路径去掉开头斜线保存文件，均为独立文件副本，非软链接或硬链接。
数据清单仍保留原路径，恢复时依据 MANIFEST.json 的 source 到 relative 映射定位副本；不得把本目录直接当作原实验目录启动。
本次未备份原始视频、未使用的额外抽帧、完整第三方软件环境和模型权重；相关外部依赖与哈希保存在 EXTERNAL_DEPENDENCIES.json 和各注册清单。
local_reference 保存当前论文Markdown、论文文件校验信息、排版脚本与分析脚本，供确认代码和论文版本关系。
SHA256SUMS 和 MANIFEST.json 覆盖全部备份载荷。代码第一版_代码与配置.tar.gz 另外封装代码及配置，不重复压缩训练数据。
BACKUP_VERIFIED.json 是成功标记；其不存在时不能视为完整备份。
